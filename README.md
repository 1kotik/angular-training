# Angular Training

## Required tools

- **Node.js**: `>=20.9.0`
- **npm**: `>=8.0.0`
- **Angular CLI**: `>=17.3.0 <18.0.0`
- **JSON Server**: https://github.com/typicode/json-server 

## Installing dependencies

```bash
npm install
```

## Running the project

```bash
ng serve
```

App will be available at: `http://localhost:4200`

## Running JSON Server

Please use database file (`db.json`) located in the project root.

Execute following command in JSON server project folder
```bash
npx json-server db.json
```


JSON server will be available at: `http://localhost:3000`
